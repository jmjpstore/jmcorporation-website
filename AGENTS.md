# Project Guidelines & Custom Rules

## Header & Contact Button Rules
- **Direct Phone Call Button**: Header right action bar contains an active contact button with `href="tel:09062771999"`. Display label should be concise: `電話でお問合せ` (Japanese) / `Inquiry` (English) without showing full telephone digits inside the button text.
- **Language Switch Button**: Positioned on the second row (bottom-right of the header action area) to maintain a neat, non-cramped layout alongside main contact buttons.
- **Company Branding**: Display "株式会社JMコーポレーション" alongside the logo with balanced mobile and desktop spacing.
